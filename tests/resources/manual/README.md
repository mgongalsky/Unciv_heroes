# Ручная проверка нейтральных городов

Файл: [neutral-cities.json](neutral-cities.json).

В игре откройте загрузку и выберите «Load from custom location», затем этот файл. Альтернатива: скопируйте всё содержимое файла и выберите «Load copied data».

На карте есть своя столица Home в (0, 0), пустой нейтральный Emptyford в (4, 0) и защищённый Guardford в (-4, 0). Рядом с каждым стоит ваш Warrior, представляющий героя, с 50 копейщиками. Гарнизон Guardford — 5 копейщиков. Карта исследована, варвары и условия победы отключены.

1. Герой в (3, 0): войдите в Emptyford. Город должен перейти вам без боя.
2. Герой в (-3, 0): атакуйте Guardford. Должен открыться тактический бой. После победы город переходит вам, герой занимает центр, атака расходуется один раз.
3. Проверьте сохранность Granary, запасов еды (17) и накопленного производства Scout (23) сразу после получения города. Получение не должно давать золото или сопротивление; Home остаётся столицей.
4. Сохраните игру и загрузите её снова: города, герои и армии должны сохраниться.
5. Для проверки выхода из незавершённого боя загрузите исходный файл заново. Выйдите из боя до победы: город должен остаться нейтральным, атака героя — израсходованной. Отдельно проверьте изменение размера окна во время боя.

Штатная загрузка и доступность входа/атаки проверены автоматически. Отображение и интерактивный бой требуют ручного прогона.

Для повторного создания файла запустите тест `com.unciv.testing.city.NeutralCityManualSaveTest` средствами IDE. Тест записывает файл только после проверки загрузки и исходных условий.
