# Историческая фикстура города

[pre-registry-city.json](pre-registry-city.json) — данные города в старом формате, до появления единого реестра мира. Файл нужен для проверки совместимости с сохранениями, которые не создаёт текущий сериализатор.

`CityLegacyFixtureTest` читает исходный JSON, проверяет историю владельцев, население, пищу, призыв и старые слоты гарнизона. Затем вставляет неизменённое описание в контейнер цивилизации формата 4 и проверяет полную загрузку, миграцию и следующий ход.

Старые слоты нельзя предварительно переписывать новым сериализатором: тогда тест перестанет проверять исходный формат. Комментарии размещены здесь, чтобы JSON оставался корректным и сохранял историческую структуру.

[../manual/README.md](../manual/README.md) описывает отдельное генерируемое сохранение для ручной проверки нейтральных городов.
