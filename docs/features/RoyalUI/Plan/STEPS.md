# Этапы Royal UI

## Существующая общая миграция

1. IN_PROGRESS — [Общая тема](STEP_01_Theme.md). Рамки, кнопки, вкладки и типографика подключены частично; остаются аудит ресурсов, платформенная проверка шрифтов и совместимость скинов.
2. IN_PROGRESS — [Игровые экраны](STEP_02_Screens.md). Частично перенесены диалоги, боевые панели, обзор героя и городские панели. Новый handoff города ещё не реализован.
3. IN_PROGRESS — [Проверки и завершение](STEP_03_Verification.md). Есть автоматические проверки форм; у общей визуальной регрессии сохраняются ранее записанные ограничения.

Эти статусы относятся к исторической общей миграции и не означают параллельного выполнения трёх задач сейчас. Прежняя остановка для просмотра настроек описана в документах этапов и сохраняется как история.
