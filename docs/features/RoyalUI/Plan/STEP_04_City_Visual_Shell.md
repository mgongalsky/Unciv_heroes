# 04. Графический каркас города

Статус: IN_PROGRESS. Последний checkpoint — `2f3984386` в ветке `feature/city-ui-checkpoint`. Текущие изменения ещё не подтверждены визуальным сравнением с референсом.

## Текущая реализация

Общий CityScreen используется в игре и автономной CitySandbox. Компактный путь относится к скину Minimal; остальные скины сохраняют прежнее представление.

CityCompactHeader показывает название города, население, статусы, выход 104×32, реальные доходы с выбором фокуса и текущую стройку. Прогресс и расчётные ходы берутся из существующей модели. Шапка пока не полностью соответствует референсу: остаются прежние ресурсные значки и компоновка ETA.

Construction использует младший бумажный селектор Units / Buildings / Events высотой 48 UI units. Выбранная категория перемещается первой, остальные группы остаются доступными. Две колонки включаются, когда ширина страницы достигает 441 и в UI units, и в координатах окна. Каталог расположен слева, полная очередь — справа; соотношение ширин 1:0,7, промежуток 14, минимальная ширина очереди 145. При меньшей ширине очередь размещается под каталогом. Обе области имеют независимую прокрутку.

Каталог использует портреты 36, заголовки 17, пояснения и причины недоступности 12 UI units, тонкие разделители и действия «?» / «+» 28×30. Полная очередь включает текущий проект с индексом 0; портреты имеют размер 26, названия — 16, действия — 24×30, минимальная высота строки — 40. Длинные названия очереди сокращаются с подсказкой. Недоступные операции блокируются.

«?» и название проекта открывают существующее описание внутри области каталога. Back возвращает каталог с сохранением прокрутки; очередь остаётся доступной. Большие действия добавления и покупки находятся в описании. Быстрое «+» добавляет проект через прежний обработчик. Устаревший ответ асинхронного расчёта не заменяет более свежий каталог.

CityConstructionVisuals использует доступные рисованные портреты бандла для Worker, Settler, Scout, Warrior, Peasant, Granary, Workshop и Library; для остальных объектов сохраняется штатный fallback. CityConstructionCategories использует junior-left/right/centre и cloth-tab; маска выделения вычисляется по альфа-каналу бумаги. Текстуры хранятся в Skin.

## Сохраняемые контракты

Игровые правила, стоимость, покупка и формат сохранений не меняются. Очередь остаётся списком названий, прогресс хранится по названию. Перестановка и удаление используют исходные индексы и существующие операции модели; постоянные ID не вводятся. Проверки возможности изменения города сохраняются. Drag-and-drop относится к [этапу 06](STEP_06_City_Construction.md).

Только CitySandbox подготавливает демонстрационную очередь Granary → Worker → Scout с третью стоимости Granary в штатном хранилище прогресса. Основная партия этими данными не изменяется.

## Файлы текущей итерации

- `core/src/com/unciv/ui/cityscreen/CityConstructionsTable.kt` — колонки, каталог, очередь и переход к описанию.
- `core/src/com/unciv/ui/cityscreen/CityConstructionCategories.kt` — бумажный селектор категорий.
- `core/src/com/unciv/ui/cityscreen/CityConstructionVisuals.kt` — портреты из бандла с fallback.
- `core/src/com/unciv/ui/cityscreen/HeroicCityStyle.kt` — сохранение локального оформления прозрачных действий.
- `CityScreen.kt`, `ConstructionInfoTable.kt`, `CitySandbox.kt` в том же каталоге — интеграция описания и демонстрационного состояния.
- `desktop/src/com/unciv/app/desktop/CityPreviewCapture.kt` — захват настоящего экрана в скрытом GL-окне и отчёт геометрии.
- `tools/capture-city.ps1` — запуск захвата из собранных классов.

Ресурсы находятся в `android/assets/UI_bundles/Heroic-Civs-LibGDX-Handoff/heroic-civs-libgdx-handoff/libgdx-ready/`. Перед фиксацией изменений нужно включить используемые изображения селектора и портретов, проверив их статус в Git; наличие локального бандла само по себе не означает, что ресурсы отслеживаются.

## Захват и фактические проверки

После native BUILD запускать `tools/capture-city.ps1 -Width 1568 -Height 690`. Скрипт экспортирует runtime classpath и запускает приложение; задачи компиляции и тестов не вызывает. Результаты записываются в `desktop/build/city-preview/`: PNG, layout.tsv и журналы процесса. Захват отключает городскую атмосферу только в своём процессе, поскольку активной партии для поиска звуков модов нет. Пользовательские настройки при завершении захвата не сохраняются.

На 15 ноября 2026 года:

- Последний native BUILD после исправления адаптивного порога прошёл за 19 секунд. git diff --check завершился с кодом 0; Git сообщил только о нормализации LF/CRLF.
- Захват 1568×690 завершился с кодом 0 примерно за 8,4 секунды; в выводе повторного запуска ошибки звука нет.
- Логическая сцена — 1363,4783×600, масштаб кадра — 1,15. Страница Construction имеет ширину 716 и высоту 331 UI units. Каталог находится слева, очередь справа. Измеренные строки каталога имеют высоту 44–61 UI units, примерно 51–70 физических пикселей.
- Отчёт включает дочерние элементы за пределами области прокрутки. Отрицательные координаты этих элементов сами по себе не доказывают нарушение clipping.
- После исправления стартовой вкладки песочницы захваты 480×690 и 400×690 завершились с кодом 0. При 480×690 сцена имеет ширину 600 UI units, страница — 588, очередь справа. При 400×690 масштаб окна 2/3; после учёта масштаба очередь расположена под каталогом, обе области имеют ширину строк 576 UI units. Отчёт подтверждает геометрию, но не качество изображения.
- UI/golden-тесты не запускались по указанию пользователя. Эталоны не обновлялись.

PNG и его JPEG-копия были переданы IDE как бинарный текст, а не как изображение. Поэтому кадр пока не просмотрен: совпадение с референсом, качество маски, шрифтов, текстур и отсутствие визуальных перекрытий не подтверждены. Для сравнения требуется передача PNG как изображения в чат. Успешная сборка и отчёт геометрии не заменяют визуальную приёмку.

## Оставшаяся приёмка

1. Сравнить заполненную очередь и открытое описание Worker с референсом.
2. Прокрутить каталог, открыть описание и вернуться; проверить сохранение позиции и независимость прокрутки очереди.
3. Добавить Worker через «+», поднять выше Granary и опустить обратно; проверить текущий проект в шапке и сохранение прогресса Granary. Удалить ожидающий проект.
4. Проверить покупку и отмену выбранного элемента очереди, включая повторяющиеся юниты, и недоступность изменений в городе без соответствующих прав.
5. Проверить узкое окно, длинные переводы, пустую очередь, смену города и выход.
