# 04. Графический каркас города

Статус: PENDING. Не начат; ближайший предлагаемый объём работы.

## Результат для просмотра

DesktopLauncherCity открывает новый визуальный вариант в песочнице: пергаментная панель слева, настоящая квадратная карта справа, шесть доступных вкладок, выбранный side-lancet №10, brocade/laurel и нижний shield-banner 65%. Первая палитра — azure. На этом этапе игровые действия ещё не подключаются; незавершённые разделы обозначены явно, без фиктивных доходов и работающих на вид кнопок.

## Изменения

Выделить минимальные используемые ресурсы нового бандла и зарегистрировать локальные стили с собственными именами. Сохранять фиксированные орнаменты, составную рамку, кириллический fallback и штатные значки ресурсов. Disabled делает серой ткань, не весь Actor. Сверить реальные размеры нарезок и метаданные, не применять единую догадку о масштабе всех PNG.

Собрать layout на Scene2D с одним viewport. Размер квадратной карты определяется доступной высотой и минимальной читаемой шириной панели; на узком окне допускается перестройка, а не растяжение гексов. Для декора Touchable.disabled. Выделить повторно используемый контейнер карты из существующего пути только в минимальном необходимом объёме.

Новый вариант включать только через sandbox. Обычный CityScreen и общие default-стили пока сохраняют прежний путь. Точные имена новых классов — предварительные в [files](CITY_HANDOFF_FILES.md).

## Проверки и остановка

BUILD; GL-проверки создания/закрытия, границ, шести вкладок, доступа к карте, масштабирования и отсутствия изменения игровых данных при переключении. Начальные размеры: 1280×800, 1920×1080, узкое окно 360×480; различать физические пиксели и логический viewport. Проверить RU/EN, отсутствие новых Texture/BitmapFont на каждом render и повторный вход.

Просмотреть actual и выбранный эталон бандла; отдельно зафиксировать визуальную приёмку. Capture-only её не заменяет. Завершить этап показом пользователю, не переходить к действиям автоматически.

Чистые правила игры не меняются. Если выделяется независимый расчёт layout, тестировать в UI-слое, не переносить его в игровой domain.

Фактический результат: только план.
