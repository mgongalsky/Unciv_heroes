# 04. Графический каркас города

## Текущий шаг: синяя палитра и заполнение сцены

По следующему просмотру пользователь выбрал единый синий акцент. CityScreen убирает внешние зазоры, задаёт левой панели высоту сцены и локально очищает кадр пергаментным цветом. Общий BaseScreen.clearColor не меняется; дополнительная фоновая картинка не добавляется. Квадрат карты ограничен доступной высотой и читаемой шириной управления.

HeroicCityStyle применяет основы azure к городским TextButton, включая вновь созданные после обновления. Обход ограничен compactRoot, CheckBox пропускаются; стили помечаются и Drawables кешируются в Skin. Disabled сохраняет серую ткань. RoyalRibbonDrawable.useAzureSelection и TabbedPager.useAzureRoyalHeader включают синий акцент только у городского экземпляра ленты; остальные экраны сохраняют прежнее оформление.

Размер герба исправлен по secondary-decor.mjs: min(width * 0.78, clamp(width * 0.58, 220, 380) * 0.65). Это заменяет прежние 65% ширины карты. Пики не менялись. Runtime-основы кнопок снова png/skin/azure/button-base-{up,over,down,disabled}.9.png; sage этим helper больше не используется.

Затронуты CityScreen.kt, HeroicCityStyle.kt, ui/utils/RoyalRibbonDrawable.kt и TabbedPager.kt, а также документы темы. Первый BUILD этой версии превысил 300 секунд. После закрытия приложения повторный native BUILD прошёл за 3 секунды. Прежний успешный BUILD за 2 секунды относится к предыдущей версии. UI/golden-тесты не запускались по указанию пользователя. После завершения сборки проверить фон без синих просветов, синюю активную вкладку и кнопки, серое disabled-состояние и уменьшенный герб. Повторная визуальная приёмка пока не выполнена.


Статус: IN_PROGRESS. Первый MVP запущен пользователем; после просмотра внесены визуальные исправления. Полный перенос ещё не завершён.

## Согласованные границы

Общий CityScreen используется в игре и через DesktopLauncherCity, без второй реализации игровых панелей. Работа идёт небольшими версиями для просмотра. UI/golden-тесты и их переработка отложены пользователем; требуется BUILD. Игровые правила, сохранения, очереди, армии и снабжение в этом этапе не меняются.

## Текущая реализация

Для Minimal при логической ширине от 900 название города, существующие вкладки и выход размещаются внутри левой панели. Справа находится квадрат карты размером min(доступная высота, ширина после резервирования читаемой панели). Шапка, выход и герб больше не занимают отдельные строки над или под картой. На узкой сцене сохраняется страница Map.

Construction, Stats, Army и Details используют существующие панели и обработчики. Выбор клетки открывает Details; выбор места улучшения переключает Map только при наличии такой страницы.

HeroicCityStyle собирает рамку панели по brocade-frame.mjs: угол 82, оси x=16/y=21, горизонтальная полоса 11.2, вертикальная 8.65. Прямые участки повторяются без продольного растяжения; последний фрагмент обрезается через UV. Углы рисуются поверх стыков.

Карта использует отдельный декор по twin-pike-frame.mjs: связанные верхние флаги и обвитые древки сохраняются целиком, до нижнего края повторяется только деревянный стержень. Правая сторона отражена горизонтально. Герб шириной 65% карты расположен поверх её нижней части. Декоративный Image в Stack имеет Touchable.disabled и не должен перехватывать ввод.

Exit city использует зелёную ткань sage и фиксированные ланцеты 18×32 с отступом 8. Рамки пока azure; полной унификации палитры всех контролов нет. PNG берутся из libgdx-ready; текстурами владеет Skin, общие default-стили не изменяются.

## Проверки и ограничения

Первоначальный BUILD прошёл за 57 секунд. Пользователь подтвердил запуск и предоставил скриншоты, выявившие неправильные стыки рамки, растяжение полос, малую карту, отдельное размещение герба и несогласованный цвет выхода.

После исправлений git diff --check прошёл. Первый BUILD превысил 300 секунд. Повторный native BUILD по просьбе пользователя прошёл за 2 секунды; компиляция исправленного варианта подтверждена. UI/golden-тесты не запускались; эталоны не менялись.

Шесть целевых вкладок, laurel/seam, полное оформление содержимого и точное визуальное соответствие остаются дальнейшей работой. Новый декор, реальные жесты карты, изменение размера окна и Android после исправлений не проверены.

## Повторный просмотр после сборки

1. Запустить DesktopLauncherCity со скином Minimal: название и выход слева, карта максимально использует высоту справа.
2. Проверить стыки углов панели и неизменный масштаб узора на длинных сторонах.
3. Проверить пики, герб поверх нижнего края карты и зелёную кнопку выхода.
4. Выбрать клетку, прокрутить и масштабировать карту; проверить доступность вкладок и узкий режим Map.
5. Открыть город из обычной игры: используется тот же экран с реальными данными.

После этой версии остановиться для просмотра, не запускать остальные этапы автоматически.

### Исправление NPE при создании городской панели

В createCompactLayout высота внутри Table.apply берётся через this@CityScreen.stage.height: собственная stage новой таблицы ещё равна null до добавления на экран. Исправление применяется к общему CityScreen игры и песочницы. Native BUILD после исправления прошёл за 11 секунд. UI/golden-тесты не запускались по согласованному ограничению. Повторный запуск DesktopLauncherCity и открытие города в игре ещё требуют ручной проверки: экран должен открыться без NPE.
