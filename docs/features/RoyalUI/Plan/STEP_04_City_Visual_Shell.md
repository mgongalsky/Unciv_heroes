## Исправления: компактные действия и очередь

После просмотра пользователь отметил переполнение Exit city. В CityCompactHeader.kt выход использует размер 104×32 и текст 16 UI units вместо произвольного масштаба 0.8. HeroicCityStyle.kt содержит отдельный компактный стиль azure без ланцетов; размер надписи рассчитывается через Fonts.ORIGINAL_FONT_SIZE, общий BitmapFont не меняется. Маркер стиля сохраняет компактное оформление при обходе кнопок и обновлении доступности.

CityConstructionsTable.kt показывает в нижней очереди только ожидающие проекты с исходными индексами от 1. Текущий проект остаётся в шапке; кнопка многоточия выбирает его и открывает доступные действия покупки в существующей полосе, стрелка вниз понижает приоритет, крестик отменяет проект. Плюс каталога и действия очереди имеют размер 32×32. Запрет изменения города проверяется перед отменой и перестановкой. Используются прежние игровые операции, модель очереди и прогресса не меняется. Это заменяет прежнее описание дублирования текущего проекта внизу.

Фактические файлы этой правки: core/src/com/unciv/ui/cityscreen/CityCompactHeader.kt, HeroicCityStyle.kt, CityConstructionsTable.kt и эти документы темы. Native BUILD прошёл за 11 секунд; diff --check прошёл до сборки. UI/golden-тесты не запускались по согласованному ограничению.

## Текущий шаг: структура панели

По замечаниям разработчика сначала исправляем распределение места, сохраняя общий CityScreen для игры и DesktopLauncherCity:

1. Компактная шапка: название слева, население рядом, статусы в той же строке, небольшой Exit city.
2. Строка реальных доходов и выбора приоритета над вкладками. Числа имеют зарезервированную ширину; при нехватке места доступна горизонтальная прокрутка.
3. Текущая стройка над вкладками: проект, прогресс и оставшиеся ходы из существующего калькулятора.
4. Каталог получает ширину панели и собственную прокрутку. Очередь размещается отдельно под каталогом и не уезжает вместе с ним. Покупка, добавление, отмена и перестановка используют существующие обработчики.

Предварительно затронуты CityScreen.kt, CityScreenCityPickerTable.kt, CityConstructionsTable.kt и новый CityCompactHeader.kt в core/src/com/unciv/ui/cityscreen/. Документы темы обновляются по фактическому результату.

## Сохраняемые контракты

Игровые правила и сохранения не меняются. Очередь остаётся MutableList<String>, прогресс хранится по названию; отдельные постоянные ID проектов не вводятся. Drag-and-drop относится к [этапу 06](STEP_06_City_Construction.md). Приоритет вызывает существующее переназначение населения и обновление экрана. Запрет изменения чужого города и города-марионетки сохраняется.

Новая работа относится к UI-адаптерам; доменные правила и отдельная копия игрового состояния не создаются. Другие скины сохраняют прежний путь.

## Сохранённый результат

Квадратная игровая карта справа ограничена высотой сцены и читаемой шириной управления. Рамка панели использует углы 82 и оси 16/21 из brocade-frame.mjs; прямые полосы повторяются с обрезкой UV. Связанные пики и герб рисуются поверх карты без перехвата ввода. Ширина герба: min(width * 0.78, clamp(width * 0.58, 220, 380) * 0.65).

Кнопки и выбранная вкладка используют локальную синюю палитру. Очистка кадра у города пергаментная; общий BaseScreen.clearColor не меняется. Исправлен NPE создания таблицы: высота берётся через this@CityScreen.stage.height. Последний BUILD сохранённой версии прошёл за 11 секунд.
