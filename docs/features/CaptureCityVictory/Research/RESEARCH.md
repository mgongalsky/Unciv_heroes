# Исследование CaptureCityVictory

Дата: 2026-10-31. Исследование завершено реализацией в ветке `feature/capture-city-victory`. Контракт: [PLAN.md](../Plan/PLAN.md). Фактические пути: [files.md](../Plan/files.md). Проверки и ручной сценарий: [CODE_GUIDE.md](../CODE_GUIDE.md).

## Опоры в существующем коде

ScenarioCity.id переносится в CityInfo.id при создании партии. Канонический WorldCityRegistry сохраняет ID при передаче. Для целей достаточно стабильного ID и снимка владельцев; отдельный журнал захватов не требуется.

GameStarter уже разрешает слоты сценария, включая Random. Реализация сохраняет полученное соответствие слот → civName. Ссылки проверяются расширением существующего ValidateScenarioUseCase.

NeutralCityEntry завершает занятие пустого нейтрального города. BattleWorldOutcomeHandler применяет результат тактического боя и перемещает героя. Старое завоевание завершается в puppetCity. Эти границы вызывают одну чистую проверку через VictoryManager.

moveToCiv используется также торговлей и дипломатическими операциями, поэтому общая передача не определяет захват.

## Принятые решения

- Требуется текущее владение всеми назначенными участнику целями и захват одной из них. Пустой набор не выигрывает. Старт и загрузка сами не создают событие захвата.
- Required включается принудительно, Forbidden исключается, Optional сохраняет выбор. Null означает первоначальные defaults; явный пустой итог диагностируется.
- Первый победитель и тип сохраняются в GameInfo. Потеря города после продолжения результат не отменяет.
- Уже выполненная обычная победа проверяется прежде нового результата захвата. Порядок обычных типов сохраняется. TriggersVictory учитывает явный сценарный Forbidden нейтрального типа.
- CaptureCity регистрируется в Ruleset.add для баз и модов и исключается из обычной проверки пустых milestones. Конкретные цели остаются в TileMap.
- AI останавливается на границах завершённых действий; продолжение возобновляет остановленный ход без повторного startTurn.

Domain содержит CaptureCityObjective и ScenarioVictorySettings. Application содержит ResolveVictoryOptionsUseCase и ProcessCityCapturedUseCase. Новые координаторы, иерархия результата и хранилище прогресса не потребовались.

## Совместимость и подтверждение

Формат карты повышен с 2 до 3, игры с 5 до 6. Старые карты получают null-политику. Историческая миграция игры версии 4 сохранена. Clone отделяет настройки, а сериализация сохраняет результат и участников.

BUILD прошёл. CityTestSuite: 58, VictoryTestSuite: 22, VictoryRegressionSuite: 10 тестов прошли. Три адресные GL render-проверки прошли. Эти результаты не подтверждают визуальное сравнение: city-editor baseline отсутствует, новые формы проверены capture-only.

Ручной сценарий и утверждение baseline остаются пользователю. Новые подписи используют английский fallback; полный перевод не добавлен. Полная переработка обычных побед и новая стратегия поиска целей AI не входили в реализацию.
