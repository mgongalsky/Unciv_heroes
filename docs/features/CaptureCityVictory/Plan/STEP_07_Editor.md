# STEP 07 — Редактор и интерфейс

Статус: реализовано. Пользователь подтвердил работоспособность основной фичи и уточнил оформление Required: красным должен быть штатный выбранный индикатор внутри кружочка, а не дополнительная точка возле названия. Под списком показывается такой же заблокированный индикатор с подписью Required. Легенда появляется только при наличии обязательных условий. Повторяющийся текст `(Required)` удалён; блокировка Required/Forbidden сохранена.

Изменение оформления находится в Scene2D-адаптере GameOptionsTable. Стиль копируется для конкретного checkbox, чтобы не перекрасить остальные элементы общей skin. Доменные правила и форматы сохранений не меняются.

Edit → Victory поддерживает режимы типов побед, Optional-defaults и несколько целей с допустимыми слотами. Применение черновика атомарно. Используемые города и слоты защищены от удаления. VictoryScreen вычисляет состояние целей по текущим владельцам и не раскрывает названий неизведанных городов.

MapOptionsTable сохраняет выбранную карту или генерацию при пересоздании; недавняя карта предлагается только при первоначальной настройке. Начальное заполнение SelectBox обрабатывает окончательный выбор. Preview проверяет легенду, отсутствие Required в подписи условия, блокировку условий, Optional-выбор и явный пустой выбор после recreate; очистка не скрывает исходные исключения.

Проверки текущей корректировки: BUILD и `com.unciv.testing.UiGoldenTest#victorySelectionRender`. Capture-only не утверждает внешний вид по baseline; эталоны не обновляются. Вручную проверить красный штатный кружок у Required, обычные индикаторы других условий и совпадающий индикатор легенды.

Новые подписи используют английский fallback. Общий путеводитель и ручной сценарий: [CODE_GUIDE.md](../CODE_GUIDE.md).
