# STEP 07 — Редактор и интерфейс

Статус: реализовано. Пользователь подтвердил работоспособность основной фичи; по его замечанию обязательные условия в меню теперь отмечены красной точкой вместо повторяющегося `(Required)`. Под списком выводится одна легенда `● Required`, только когда есть обязательные условия. Блокировка Required/Forbidden сохранена.

Edit → Victory поддерживает режимы типов побед, Optional-defaults и несколько целей с допустимыми слотами. Применение черновика атомарно. Используемые города и слоты защищены от удаления. VictoryScreen вычисляет состояние целей по текущим владельцам и не раскрывает названий неизведанных городов.

Изменение индикатора находится только в Scene2D-адаптере GameOptionsTable; доменные правила и форматы сохранений не менялись.

При повторной проверке формы обнаружено, что автоматический подбор недавно сохранённой карты при recreate подменял уже выбранную генерацию и применял чужие Required-правила. MapOptionsTable теперь сохраняет выбранную карту или генерацию при пересоздании; недавняя карта предлагается только при первоначальной настройке. Начальное заполнение SelectBox обрабатывает окончательный выбор, а не промежуточный первый элемент.

Preview проверяет общую легенду, отсутствие Required в подписи условия, блокировку условий, Optional-выбор и явный пустой выбор после recreate. Очистка preview не скрывает исходные исключения и не освобождает старый экран повторно.
