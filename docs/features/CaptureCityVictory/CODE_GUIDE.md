# CaptureCityVictory — путеводитель

## Правило

`core/src/com/unciv/pure/domain/victory/CaptureCityObjective.kt` хранит ID города и допустимые слоты. Участник должен одновременно владеть всеми назначенными ему целями. Пустой набор не даёт победу. Для завершения требуется событие захвата одной из назначенных целей; старт, торговля и загрузка не являются такими событиями. Текущее владение другими целями учитывается без журнала истории.

`core/src/com/unciv/pure/domain/scenario/ScenarioVictorySettings.kt` содержит Required/Optional/Forbidden и цели. Настройки копируются глубоко.

`core/src/com/unciv/pure/application/scenario/ResolveVictoryOptionsUseCase.kt` разрешает выбор игрока: null означает первоначальную настройку, пустая коллекция — явный выбор. Required включается, Forbidden исключается; недоступный Required и пустой итог отклоняются.

`core/src/com/unciv/pure/application/victory/ProcessCityCapturedUseCase.kt` проверяет завершённый захват на значениях. `ValidateScenarioUseCase` проверяет ссылки и дубликаты. Чистое ядро не зависит от GameInfo, Gdx, UI, файлов или DI.

## Игровые адаптеры

`VictoryManager.onCityCaptured` сопоставляет civName со стабильным слотом и передаёт снимок владельцев чистой операции. Его вызывают NeutralCityEntry после занятия пустого города, BattleWorldOutcomeHandler после применения боя и переноса героя, CityInfoConquestFunctions после завершения puppetCity. Общие moveToCiv и WorldCityRegistry.transfer не проверяют победу.

Результат хранится в GameInfo.victoryWinner/victoryType. recordVictory фиксирует только первый результат. Обычные победы проверяются в прежнем порядке включённых типов; CaptureCity исключён из проверки пустых milestones. Уже выполненная обычная победа имеет приоритет перед новым событием захвата. Для TriggersVictory сохраняется старое поведение, кроме явного сценарного Forbidden для нейтрального типа.

NextTurnAutomation останавливается между операциями/юнитами. GameInfo.nextTurn сохраняет границу остановленного хода AI. Продолжение не выдаёт ему startTurn повторно; VictoryScreen возобновляет приостановленную цепочку через WorldScreen.nextTurn. Офлайн-просмотр остаётся у человека.

## Форматы и запуск

Карта: версия 3; последовательная миграция старых карт оставляет scenarioVictorySettings = null. Игра: версия 6; новые поля читаются/пишутся существующей сериализацией GameInfo. Формат 4 с городами внутри цивилизаций продолжает мигрировать в каноническую коллекцию. Исторические фикстуры не переписаны.

Настройки партии принадлежат её TileMap. Отдельной второй копии настроек в GameInfo нет. scenarioVictoryParticipants хранит слот → civName после Random. Clone отделяет настройки и назначения; простой результат сохраняется после загрузки и продолжения.

MapSaver.loadScenarioVictorySettings читает облегчённое превью той же миграцией. GameStarter повторно проверяет полный сценарий и ограничения до создания городов. Карты без авторской политики сохраняют прежний контракт прямого запуска.

CaptureCity регистрируется как встроенный сценарный тип в Ruleset.add для базовых правил и модов; мод может переопределить оформление. Цели конкретной карты не попадают в RulesetCache. Базовые VictoryTypes.json не переписывались.

## Интерфейс

Edit → Victory: ScenarioVictoryEditorPanel редактирует режимы, Optional-defaults и несколько целей с допустимыми слотами. Apply публикует проверенный черновик одной командой. Возврат к выбору игрока удаляет политику карты. ScenarioCityEditorCommands защищает используемые города и слоты от удаления.

NewGameScreen/GameOptionsTable отображают ограничения и ошибку конфигурации. victorySelectionInitialized отличает defaults от явно пустого выбора после пересоздания экрана. VictoryScreen вычисляет состояние целей из владельцев; неизведанные города показываются без раскрытия названия.

Новые строки используют переводимые ключи и английский fallback; отдельный полный перевод новых подписей не добавлен.

## Ручная приёмка

1. В редакторе создать два города и слоты игроков. В Victory сделать CaptureCity Required, остальные типы Forbidden, обе цели назначить одному слоту. Применить, сохранить, открыть карту повторно: назначения сохранены. Удаление используемого города/слота отклоняется понятным сообщением.
2. В меню проверить заблокированные Required/Forbidden. Для Optional изменить галочку и обновить экран: выбор сохранён.
3. Запустить карту. Начальное владение и загрузка не дают победу. Занять первую цель — партия продолжается; занять последнюю — появляется CaptureCity Victory. Проверить пустой нейтральный город и город после тактического боя.
4. Продолжить, сохранить и загрузить: первоначальный победитель остаётся. Повторить финальный захват AI: результат виден человеку, дальнейшие действия остановлены; «Ещё ход» возобновляет игру.
5. Просмотреть новые формы на нужном размере окна. Просмотреть actual-снимки в tests/golden/results/windows-11; только после визуального утверждения создать недостающие baseline и выполнить соответствующее сравнение.
