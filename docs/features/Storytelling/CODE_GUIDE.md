# Путеводитель Storytelling

Состояние: подготовлено исследование и план; производственного кода новой функциональности пока нет. Этот документ будет обновляться по фактической реализации.

Точки существующего кода: GameStarter создаёт сценарий, TileMap хранит исходные описания, GameInfo — состояние партии. MapUnit уже содержит instanceName и Hero. Редактор использует команды Apply и независимые черновики; WorldScreen показывает интерфейс мира.

Планируемые границы: `pure/domain` — сюжетные значения и правила; `pure/application` — обработка сценария; `logic` — игровые эффекты и хранение; `ui` — редактор, разговоры и видеосцены. Pure-тесты не используют GameInfo, Gdx, DI или файлы.

Проверки новой функциональности ещё не запускались. Поддержка видео, формат новых данных и конкретные классы тестов ещё не реализованы. Не использовать этот документ как подтверждение готовности.
