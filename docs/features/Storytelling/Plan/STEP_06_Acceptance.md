# 06 — Демонстрация и регрессия

Статус: IN_PROGRESS. Демонстрация реализована, оба игровых исхода проверены автоматически. Ручная визуальная приёмка не выполнена.

## Запуск примера

1. Открыть редактор карты → Edit → Story → Create story example map. При несохранённых изменениях редактор предлагает обычное подтверждение замены.
2. Проверить вкладки Heroes и Story. Пример содержит слот first, героя guide (Проводник) в (1,0), зону approach в (2,0) и нейтральный город gate с одним Spearman в (4,0).
3. Сохранить карту через Save. Начать новую игру на ней с одним человеком, назначив ему слот Traveller / first; отключить варваров и города-государства для воспроизводимого прохождения.
4. Подтвердить текстовый fallback вступительного ролика и вступительную реплику. Файл Videos/story-gate-intro.webm намеренно не поставляется; декодер не реализован.
5. Направить героя к (3,0). Вход в (2,0) останавливает маршрут и показывает предупреждение. Продолжить реплику и подойти к воротам.
6. Начать атаку ворот. В предбоевом разговоре задать дополнительный вопрос и вернуться к предложению. Сохранить игру до окончательного ответа и загрузить её.
7. Выбрать мир: атака отменяется, гарнизон остаётся невредимым, игрок получает 17 золота. Следующее движение показывает немодальную реакцию на флаг peace.
8. Повторно начать миссию с исходной карты и выбрать бой. Устанавливается флаг fight, разрешается отложенная атака; при следующем движении следует другая реакция. Мирная награда не выдаётся. Боевой результат зависит от армии игрока.

Новая игра не наследует прогресс предыдущего прохождения. Описание карты не меняется после выбора в партии.

Для детерминированного боя тест усиливает армию и использует тактическое исполнение AI после человеческого сюжетного ответа.
