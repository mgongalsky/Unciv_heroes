# 07 — Рабочий интерфейс редактора

Статус: реализация и адресные автоматические проверки выполнены. Визуальная приёмка открыта.

## Изменения

ScenarioHeroPreview отображает спрайт типа войска и имя без создания MapUnit. EditorMapHolder и MapEditorHeroesTab обновляют превью после Apply/Delete, обновления карты, загрузки и пересоздания экрана.

Разделы Story размещены в две строки. Выбранный раздел выделен, показаны заголовок, число записей и пояснение для пустого списка. Переключение возвращает прокрутку к началу.

Preview dialogue и Preview cinematic проверяют черновик без Apply. StoryScenePreview использует AdvanceStory и независимый StoryProgress. Ответы и флаги проходят общий движок; мировые последствия показываются без применения. Видеосцена открывается через StoryCinematicScreen; продолжение запускается после возврата в редактор.

Save → Save and play сохраняет снимок и открывает NewGameScreen с выбранной картой. Сценарные слоты назначаются участникам: первый — человек, остальные — AI; назначения можно изменить. Города-государства для карты со слотами отключены. Штатные проверки запуска сохранены. Повторная запись блокируется; isDirty сбрасывается только для той же карты и editRevision.

## Подтверждённые проверки

ScenarioStoryEditorRenderTest PASSED, 22 секунды:

- спрайт и подпись после Apply, обновления, пересоздания и Delete; отсутствие MapUnit и дубликатов;
- координатные клики Stage, hit testing, прокрутка, отказ при неверном ID и сохранение черновика;
- диалог, ответ, два последствия, завершение и закрытие без изменения карты;
- кнопка видеосцены, текстовая замена, подтверждение и возврат через стек экранов;
- Save and play, запись уникального тестового файла, сохранённый сюжет и герой, выбор карты и слотов в NewGameScreen, сброс isDirty. Тестовый файл удаляется.

Итоговый BUILD PASSED, 6 секунд. Проверка diff перед обновлением документов прошла.

Прежние тесты вызывали обработчики напрямую. Новая проверка сначала ошибочно проверяла координаты до кадра: ScrollPane размещает содержимое при draw. После исправления теста производственная прокрутка прошла проверку; первоначальная отрицательная координата не доказывала её дефект.

## Ограничения и финальный просмотр

Реального видеодекодера нет: показывается авторский fallbackText. Предпросмотр начинается с пустыми флагами. Большие диалоги редактируются длинной формой. Конкурентное редактирование во время сохранения отдельно не протестировано.

UI-тест не нажимает Start game и не проходит WorldScreen целиком. Настоящий GameStarter и оба исхода демонстрации проверены отдельными интеграционными тестами предыдущего этапа. Захват кадров не является сравнением с утверждённым эталоном.

Маршрут финального просмотра: Create story example map → спрайт Проводника → Dialogues → Preview dialogue → ответ и закрытие → Cinematics → Preview cinematic → Continue → Save → Save and play → карта и участники → Start game. Для воспроизводимого примера отключить варваров. Проверить читаемость, длинные ответы и небольшое окно. Пользовательская визуальная приёмка ещё не выполнена.
