# 03 — Игровые события и сохранения

Статус: IN_PROGRESS.

## Реализовано

GameStarter публикует начало миссии после подготовки мира. Загрузка и clone не исполняют сюжет. GameInfo сохраняет очередь, флаги, выполненные триггеры, текущую реплику и контекст ожидающей атаки.

StoryMapEvents переводит шаг движения и новую видимость героя в события. UnitMovementAlgorithms ставит последствия в очередь во время маршрута и исполняет их после размещения героя. При срабатывании маршрут останавливается на допустимой клетке. Посещение относится к достигнутой клетке. MapUnit.doAction, GameInfo.nextTurn и WorldScreen.nextTurn учитывают ожидающую очередь.

Battle.attack вызывает StoryBattleEvents.beforeAttack до боевого экрана и расходования атаки. Ожидающее решение хранит владельца, ID атакующего, ID цели и координаты. StoryBattleEvents.resume проверяет актуальную допустимость, расходует решение и продолжает конкретную атаку без повторного события. Отмена, исчезновение гарнизона и повторное продолжение не запускают бой. AI использует авторский ответ синхронно.

Проверить восстановление мира с ожидающей атакой после setTransients, а не только JSON-контракт. Ручная визуальная приёмка не выполнялась.
