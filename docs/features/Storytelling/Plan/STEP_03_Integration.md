# 03 — Игровые события и сохранения

Статус: IN_PROGRESS.

## Реализовано

GameStarter публикует начало миссии после подготовки мира. Загрузка и clone не исполняют сюжет. GameInfo сохраняет очередь, флаги, выполненные триггеры, текущую реплику и контекст ожидающей атаки.

StoryMapEvents переводит шаг движения и новую видимость героя в события. UnitMovementAlgorithms ставит последствия в очередь во время маршрута и исполняет их после размещения героя. При обязательной сцене маршрут останавливается на допустимой клетке. Посещение относится к достигнутой клетке.

StoryRuntime.isMapActionBlocked разрешает действия только при пустой очереди или очереди немодальных линейных диалогов без ожидающей атаки. MapUnit.doAction, движение и WorldScreen.canChangeState используют эту проверку. GameInfo.nextTurn, WorldScreen.nextTurn и начало боя удерживаются при любой незавершённой очереди.

Battle.attack вызывает StoryBattleEvents.beforeAttack до боевого экрана и расходования атаки. Ожидающее решение хранит владельца, ID атакующего, ID цели и координаты. StoryBattleEvents.resume проверяет актуальную допустимость, расходует решение и продолжает конкретную атаку без повторного события. Отмена, исчезновение гарнизона и повторное продолжение не запускают бой. AI использует авторский ответ синхронно. StoryPresentation вызывает resume после завершения очереди на следующем кадре.
