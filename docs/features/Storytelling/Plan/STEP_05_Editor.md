# 05 — Редактор сценария

Статус: PENDING.

Цель: настраивать героев, зоны, триггеры, диалоги и последствия через интерфейс редактора.

Следовать существующему контракту черновик → проверенная команда Apply → isDirty. Выбор клеток показывает зоны и размещения. Фильтры предлагают любого героя или стабильный ID конкретного героя с читаемым именем. Слоты используются существующие. Удаление объектов, на которые есть ссылки, должно отклоняться с объяснением.

Проверки: ошибка без частичной записи, независимость черновика, Apply/Delete, сохранение и повторное открытие, переключение вкладок/кисти, resize, длинные строки и небольшое окно. Новые строки делать переводимыми. Включить реальную настройку ветвящегося диалога, а не только JSON-поле.

Результат: ещё не реализовано и не проверено.
