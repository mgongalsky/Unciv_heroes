# 05 — Редактор сценария

Статус: IN_PROGRESS — формы подключены, автоматические проверки пройдены; визуальная приёмка ещё не выполнена.

## Реализовано

Edit → Heroes позволяет выбрать клетку, создать героя, изменить его ID, имя, тип войска и слот владельца, применить или удалить описание. Edit → Story предоставляет формы зон, триггеров, диалогов, ответов, последствий и описаний видеосцен. Клик карты переключает принадлежность клетки выбранной зоне и обновляет подсветку.

Общий черновик сюжета независим от карты. Переключение разделов Story сохраняет ввод в черновике; Apply проверяет ссылки и значения до публикации. Discard восстанавливает сохранённые значения. Выход из вкладки отбрасывает неприменённый черновик. Герой также сохраняется только через Apply.

Диалоги редактируются через поля и списки: узлы, переходы, ответы, условия, последствия и авторский ответ AI. JSON-ввод не требуется. Изменение стабильного ID не переписывает ссылки автоматически: несогласованный результат отклоняется при Apply.

Команда ScenarioStoryEditorCommands проверяет весь набор героев и сюжет до записи. Удаление используемого героя отклоняется. Соседние инструменты городов и слотов учитывают сюжетные ссылки из триггеров и ответов. Проверки типов войск используют переданный ruleset, не требуя игровой инициализации BaseUnit.

## Выполненные проверки

- ScenarioStoryEditorCommandsTest: 6 тестов прошли. Проверены независимость черновика, повторный Apply, отказ без частичной записи, защита ссылок и сериализация карты с героем, зоной и ветвящимся диалогом.
- ScenarioStoryEditorRenderTest: проверка в настоящей GL-сессии прошла. Выполнены ввод и Apply через виджеты, отказ при неверном ID, сохранение ввода между разделами, повторное открытие, ограничение ширины форм, выбор клетки, переключение Heroes/Story/Terrain/View и пересоздание MapEditorScreen.
- BUILD проходил при подключении форм; последующие адресные тесты также скомпилировали изменённый код.

## Остаётся

Просмотреть фактические кадры hero-editor и story-editor; эталоны не утверждены. Capture-only проверяет поведение и создаёт снимки, но не выполняет визуальное сравнение. Отдельно проверить небольшое окно, длинные подписи и удобство прокрутки большого диалога. Полный демонстрационный путь от редактора до двух игровых исходов относится к этапу 06.
