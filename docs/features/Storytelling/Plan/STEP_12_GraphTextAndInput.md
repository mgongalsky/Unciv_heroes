# Этап 12 — размер текста и клики по ответам

Статус: реализация и автоматические проверки выполнены.

## Причины и результат

Абсолютный setFontScale(0.75/0.8) при ORIGINAL_FONT_SIZE = 50 увеличивал подписи формы и кнопки. Теперь используется локальный setFontSize: 16 для компактных подписей и 18 для кнопки добавления. Общий skin не изменяется. У CheckBox отключён перенос подписи: Pause world располагается горизонтально рядом с переключателем.

Пользователь уточнил, что не работал клик по Continue. Это служебная строка узла без вариантов ответа: ранее её Label не получал обработчик редактирования, поэтому клик выбирал карточку. Теперь он создаёт первый ответ и открывает TextArea прямо внутри карточки. Существующие ответы продолжают редактироваться без создания новых.

## Выполнение и границы

StoryDialogueGraphCanvas.installTextEditing подключает отдельный callback для Continue. Событие не всплывает в обработчик выбора карточки. StoryDialogueGraphScreen.addAnswer принимает ID нажатого узла, фиксирует прежние поля и вызывает существующую EditStoryDialogue.addAnswer. Первый ответ наследует nextNodeId и назначается выбором AI. Затем openInline открывает редактор с клавиатурным фокусом.

Новая логика относится к UI-адаптеру. Domain/application и форматы сохранений не изменены; используется существующая проверенная команда. До Apply изменения остаются в черновике; Cancel их отменяет. Создание ответа и ввод текста доступны в Undo/Redo.

## Проверки

- com.unciv.testing.ScenarioStoryEditorRenderTest — PASSED, 24 секунды.
- BUILD — PASSED, 11 секунд.

UI-сценарии проверяют размеры подписей и ширину Pause world после раскладки, клики по существующим ответам при масштабах 1.0/0.65/1.3, межкадровое обновление и небольшой сдвиг мыши, переключение фокуса и синхронизацию формы. Отдельная проверка нажимает Continue в невыбранной карточке через установленный inputProcessor, вводит текст, выполняет Undo/Redo и Apply, проверяет сохранение перехода, назначение AI и неизменность исходного графа.

Capture-only не является сравнением с визуальным эталоном. Эталоны не обновлялись.

## Ручная приёмка

В редакторе диалога проверить горизонтальную подпись Pause world. В карточке без ответов нажать Continue, ввести текст в появившееся поле внутри карточки и нажать Escape. Убедиться, что текст сохранён в черновике, а стрелка ведёт к прежнему узлу. Пользовательская визуальная приёмка этой версии ещё не выполнена.
