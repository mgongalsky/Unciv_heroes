# 01 — Сценарные герои

Статус: реализация и адресные проверки завершены; ожидается локальный коммит этапа. UI расстановки относится к [этапу 5](STEP_05_Editor.md).

## Реализация

`ScenarioHero` хранит стабильный ID, отображаемое имя, тип наземного военного юнита, слот и точную клетку. Локальные инварианты находятся рядом с моделью. `PrepareScenarioHeroesUseCase` проверяет ссылки, повторные ID/позиции, назначения участников и занятость, возвращает отдельные копии описаний.

`TileMap.scenarioHeroes` хранит исходные данные. `MapUnit.scenarioHeroId` сохраняет сюжетную идентичность, существующее instanceName — имя. Clone и copyStatisticsTo переносят ID; копирование описаний независимо.

`InstantiateScenarioHeroesUseCase` вызывается из GameStarter.addCivStartingUnits. Проверяет и подготавливает весь набор до размещения. Старт напрямую размещает юнит без putInTile/moveThroughTile: посещение, руины и захват города не выполняются. Герой не может стартовать в чужом или нейтральном городе. Предсказуемые ошибки размещения проверяются до регистрации; общей транзакции отката произвольных ошибок движка не вводилось.

Участники с заданными героями не получают дополнительный стандартный отряд, включая миссии без города. Позиция героя служит стартовым ориентиром; при наличии столицы её прежний приоритет сохраняется. Загрузка партии не вызывает создание героев повторно.

Формат карты — 4, игры — 7. Старые карты получают пустой список размещений; старые юниты — пустой сценарный ID. Удаление используемого героем слота защищено. Типы героев проверяются на границе ruleset.

## Проверки

- BUILD после производственных изменений — PASSED.
- PrepareScenarioHeroesUseCaseTest — 6 чистых тестов, PASSED.
- ScenarioHeroInstantiationTest — полный класс PASSED; в исходнике 6 методов @Test, IDE сообщает 7 результатов. Не трактовать этот счётчик как семь отдельных методов.
- ScenarioGameStarterTest и ScenarioCityMapFormatTest прошли в адресном регрессионном запуске вместе с адаптером.
- ScenarioGameStarterTest#scenarioHeroWithoutCitySurvivesSaveAndIndependentRestart — PASSED: настоящий запуск без города, один герой, сохранение нового имени и ID, повторный независимый запуск исходной карты.

Проверены точное размещение, запрет повторного создания, ошибка второй позиции без частичной регистрации, оба формата карты, копирование, миграция старой карты, перенос личности при замене и отсутствие захвата нейтрального города на старте. Проверка copyStatisticsTo покрывает перенос свойств, а не весь UI-путь покупки улучшения.

## Ограничения

Начальная армия и характеристики используют существующие defaults типа юнита; отдельной настройки войск героя пока нет. Слоты разрешаются через существующее scenarioVictoryParticipants — это уже сохраняемый реестр слот → нация, несмотря на историческое имя. Тактические правила не изменялись.
