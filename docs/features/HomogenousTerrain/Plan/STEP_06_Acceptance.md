## Ручная приёмка

1. Из корня проекта запустить `desktop:runTerrain` через Gradle-конфигурацию IDE. Launcher работает из android/assets.
2. В поле пути указать абсолютный путь приведённого result.json и нажать Open snapshot / report.
3. Нажать Generate / repeat: seed 42, поля и метрики должны сохраниться.
4. По очереди изменить климат на 12, растительность на 6 и рельеф на 4, каждый раз возвращая остальные масштабы к 6/3/2. Сравнить с соответствующими каталогами серии.
5. Вернуть 6/3/2 и повторить генерацию: исходный результат должен восстановиться.
6. Переключить пять слоёв, затем Show game terrain; проверить прокрутку, zoom, читаемость формы и метрик. Show selected layer возвращает PNG.
7. Просмотреть `tests/golden/results/<платформа>/terrain-playground-actual.png` и `terrain-parameters-actual.png`. Только после одобрения намеренно создать baseline соответствующими методами UiGoldenUpdateTest и выполнить методы сравнения UiGoldenTest.

Ручная оценка не заменяет автоматические проверки и не означает выбор окончательного баланса.
