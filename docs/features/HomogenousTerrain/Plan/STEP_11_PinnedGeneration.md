# Этап 11 — закреплённая генерация и доступный низ формы

Статус: DONE.

## Цель и контракт

В Generate под селектором слоя закреплена одна кнопка Generate. Каждое принятое нажатие выбирает новый положительный случайный seed, отличный от предыдущего, и полностью создаёт карту с текущими настройками формы. Во время работы кнопка заблокирована, обработчик дополнительно отклоняет повторный запуск. После завершения редактор остаётся в Generate. Кнопка общая для New map и Partial; отдельная генерация выбранного шага Partial сохранена.

Нижние элементы раскрытой формы доступны прокруткой. Закреплённые инструменты остаются видимыми.

## Реализация и границы

GenerationPage отключает внешнюю прокрутку при активации Generate и восстанавливает её при выходе. Вложенный MapEditorGenerateTab размещён в Container с нулевым минимальным размером и получает оставшуюся высоту viewport. Форму прокручивает внутренний pager. Общий TabbedPager не менялся.

MapEditorLayerControls размещает regenerateButton под селектором. Нижняя дублирующая кнопка полной генерации удалена. MapEditorGenerateTab выбирает seed после проверки параметров и перед снимком для фонового генератора. MapParametersTable.reseed принимает необязательное явное значение и синхронизирует поле с моделью; прежние вызовы без аргумента сохранены.

Сохранение настроек после генерации отделено через persistGenerationDefaults в MapEditorScreen. Производственный адаптер по умолчанию выполняет прежнее сохранение; UI-сценарий использует пустой обработчик и не записывает пользовательские настройки. При recreate обработчик сохраняется.

Это изменение UI-адаптеров и координации запуска. Чистые domain/application-правила террейна, формат карт и поведение генератора при заданном seed не изменены; новых чистых правил для отдельных unit-тестов нет.

## Ручная приёмка

На привычном размере окна открыть редактор → Generate → New map, раскрыть Advanced Settings и прокрутить до низа: Reset to defaults виден полностью, Generate остаётся под селектором слоя. Нажать Generate, дождаться карты и нажать снова: seed меняется, настройки сохраняются, раздел Generate остаётся открытым. Этот ручной просмотр пользователем ещё не подтверждён.
