## Контракт и реализация

LatitudeRange в domain проверяет градусы −90…+90 и порядок границ. Максимальный Y соответствует верхней широте, минимальный — нижней. Равные широты дают постоянный фон. Для единственной строки используется середина диапазона; допуск 0.0001 по Y учитывает Float-погрешность координат.

TerrainGenerationPipeline передаёт спроецированную широту в общий ClimateGenerator с максимумом 90°. Координаты шума и выходная геометрия сохраняются. Отсутствие диапазона оставляет прежнюю арифметику и RNG. Flat Earth с диапазоном отклоняется до генерации. Обычный игровой адаптер не получает новую настройку.

TerrainExperimentFiles сохраняет диапазон и версию `homogenous-terrain-latitude-1`. Старый режим сохраняет `homogenous-terrain-1` и прежние байты канонического JSON без нового поля. Версия, checksum и повторное вычисление проверяются при чтении.

CLI принимает парные `--top-latitude` и `--bottom-latitude`; `--latitude-mode=legacy` явно отключает диапазон. Без переопределения повтор отчёта сохраняет его настройки. Ошибочные комбинации отклоняются до создания каталога.

В песочнице размеры находятся в начале панели. Видны только размеры выбранной формы. Latitude model переключает Legacy и Latitude range. Generate сохраняет исходную сетку, Create new land mask применяет размеры и создаёт новый исходный снимок. Открытие отчёта восстанавливает широты; ошибка не заменяет показанный результат.

- BUILD прошёл.
- TerrainGenerationTestSuite: 39 тестов, включая 4 LatitudeRangeTest и 7 TerrainGenerationPipelineTest.
- TerrainGenerationCharacterizationTest: 8 тестов, прежние 36 отпечатков и RNG сохранены.

- UiGoldenTest#terrainPlaygroundRender: прошёл расширенный сценарий. Проверены прямоугольник 7×5, гексагон радиуса 3, диапазон 60°…20°, фиксация черновика до потока, повтор, ошибочная широта и открытие отчёта с диапазоном.

Capture сохраняет actual и проверяет обработчики, но не утверждает визуальный baseline.

## Ручной сценарий

1. Перезапустить прежнюю Gradle-конфигурацию с задачей `desktop:runTerrain`.
2. В начале панели выбрать New grid shape = rectangular, width = 40, height = 30. Для квадратного контура можно задать 30×30; клетки остаются гексами.
3. Задать Seed = 42, масштабы 6/3/2, Generation mode = ALL, Latitude model = Latitude range, верхнюю широту 60, нижнюю 20. При необходимости прокрутить левую панель.
4. Нажать Create new land mask: получить сетку из 1200 клеток. Нажать Show game terrain для игровых текстур.
5. Не менять seed и размеры. Задать широты 20 и −20, нажать Generate / repeat, затем Show game terrain. Ожидается более тёплый климатический фон вокруг экватора, но не гарантированный набор террейнов.
6. Вернуть 60 и 20, нажать Generate / repeat: результат должен повторить шаг 4. Для числового сравнения выбрать TEMPERATURE и Show selected layer.
7. Выбрать hexagonal, radius = 12 и нажать Create new land mask: получить 469 клеток. Сравнить с radius = 20: 1261 клетка. Само изменение поля без Create не меняет сетку.
8. В режиме диапазона задать 100° и нажать Generate: должна появиться ошибка, прежний результат сохраниться. Вернуть допустимое значение.

Seed задаёт случайность, но не идентичный рисунок при изменении геометрии: меняются соседство, порядок обхода и распределение широт. Это инструмент подбора исходной поверхности, а не окончательный баланс миссий.
