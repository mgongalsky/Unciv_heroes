## Реализация

pure/domain/mapgeneration/PerlinNoise.kt содержит единственную реализацию шума. logic/map/Perlin.kt делегирует ей, сохраняя API и defaults. Usages проверены для генератора, рек и BattlefieldTerrain.

ClimateGenerator.kt содержит значения клеток, настройки, интервалы, климатические формулы и выбор первого совпадения. Сохранены Float.ulp для специальных минимумов, открытые нижние границы, fallback, радиальная модель Flat Earth и отсутствие записи климатических полей в исторической ветке без условий.

TerrainGenerationAdapter.applyClimate преобразует правила и координаты и вызывается из MapGenerator.applyHumidityAndTemperature. Результат вычисляется до публикации оснований. Недопустимый масштаб отклоняется до RNG и изменений карты. Legacy transients остаются обязанностью адаптера.

## Проверки

BUILD, PerlinNoiseTest (4) и ClimateGeneratorTest (6) прошли. Исторические отпечатки слоёв и расход RNG сохранены. Экспериментальный путь сопоставлен на одинаковых входах; финальная чистая suite из 33 тестов также прошла.

## Границы

Лёд остаётся legacy-этапом с прежним API шума. Неиспользуемые getTemperatureAtRadius, getTileRadius и scaleToRange удалены из MapGenerator после проверки usages. Используемые льдом интервалы правил сохранены. Повторяемость полного generateMap проверена отдельно в этапе 06 и не выдаётся за исторический эталон всего конвейера.
