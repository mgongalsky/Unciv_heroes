# Этап 01. Контракты и характеристические проверки

Статус: DONE.

[План](PLAN.md) · [Этапы](STEPS.md) · [Файлы](files.md)

## Фактический результат

Проверена ветка feature/homogenous-terrain; посторонние изменения рабочего дерева сохранены. Прослежены вызовы генератора из GameStarter, главного меню и редактора. На карте без юнитов инициализация transients не требует GameInfo.

TerrainGenerationCharacterizationTest фиксирует 36 исторических отпечатков выделяемых слоёв: seed 1, 42, −17; Hexagonal, Rectangular, Flat Earth Hexagonal; рельеф, климат, растительность и последовательность трёх слоёв. SHA-256 включает порядок клеток, координаты, основания, порядок особенностей и климатические поля. Отдельно проверяется следующий RNG.nextInt.

Эталоны получены до переключения на чистые реализации и проверены после каждого переключения. Данные находятся в тестовом классе; отдельный characterization.json не создавался.

Проверены исключения воды и гор, первое совпадение, fallback, историческая ветка без климатических условий, допустимость леса, Float-границы диапазонов и точность геометрии экспериментальной сетки относительно TileMap.

## Контракты

- Float-координаты HexMath преобразуются в Double без изменения порядка операций.
- Отдельный этап начинает RNG заново; последовательность использует один поток.
- Экспериментальный seed 0 воспроизводим; legacy API по-прежнему заменяет 0 временем.
- TileMap.clone не является снимком климатических полей; эксперимент использует собственные глубокие снимки.
- Порядок HashSet кандидатов растительности сохраняется адаптером в списке. Характеристическая фикстура с одним типом не обещает стабильность identity hash между JVM; несколько упорядоченных кандидатов проверяются чистыми тестами.

## Проверки и границы

BUILD и 8 тестов TerrainGenerationCharacterizationTest прошли, включая сравнения экспериментального координатора с историческими результатами.

Последовательность трёх слоёв не равна полному generateMap. Отдельные интеграционные проверки полного генератора описаны в этапе 06; исторический эталон всего конвейера не получен. Создание новых экспериментальных сеток с wrap отклоняется; метрики поддерживают явные замкнутые графы.
